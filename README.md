# Twitch Chat Bot Manager

Bot para gerenciar múltiplas contas no chat da Twitch usando proxies.

## Instalação
```bash
pip install -r requirements.txt
```

## Configuração
1. Adicione seus tokens em `configs/tokens.txt`
2. Adicione seus proxies em `configs/proxy.txt`
3. Configure os canais em `configs/channels.txt`
4. Configure as mensagens em `configs/messages.txt`

## Uso
```bash
python main.py
```

## Recursos
- Interface em tempo real
- Suporte a múltiplos tokens
- Sistema de proxy
- Mensagens aleatórias
- Gerenciamento de delays
